# 루미큐브

승인 회원 2–4명 온라인 게임. 도구 메뉴의 마블룰렛 바로 아래에 표시합니다.

# 적용 규칙과 내기 동점 처리

기본 판정은 [제조사 Classic 공식 설명서](https://rummikub.com/wp-content/uploads/2019/12/2600-English-1.pdf)를 기준으로 합니다.

| 항목 | 적용 |
|---|---|
| 인원·타일 | 2~4인, 숫자 104장과 조커 2장, 각 14장 |
| 시작 | 각자 타일 숫자를 추첨, 높은 숫자가 선. 동점자 재추첨 후 타일 반환·재혼합 |
| 그룹·런 | 다른 색 같은 숫자 3~4장 / 같은 색 연속 숫자 3장 이상, 13 다음 1 금지 |
| 첫 등록 | 내 패만으로 합계 30점 이상. 조커는 대신하는 숫자로 계산 |
| 재조합 | 첫 등록 다음 차례부터 허용, 턴 종료 시 모든 조합이 유효해야 함 |
| 먹기 | 1장 먹고 바로 턴 종료, 새로 먹은 패는 다음 차례부터 사용 |
| 조커 | 공용판에서 가져온 조커를 손패에 넣을 수 없으며 해당 차례에 다시 사용 |
| 시간 | 1분. 미완성 재조합은 원복하고 3장 벌칙, 미변경은 1장 먹기 |
| 종료 | 손패를 비우면 승리. 풀이 비고 모두 연속 패스하면 남은 합계가 최소인 사람이 승리 |
| 점수 | 승자는 다른 사람 벌점 합의 양수, 나머지는 남은 타일 합의 음수. 조커는 30점 |

미등록 -100점/조커 -50점은 이 Classic 규칙에 섞지 않습니다. [뉴질랜드 대회 규칙](https://rummikub.co.nz/wp-content/uploads/2024/05/NZRC-Offical-Playing-Rules.pdf)처럼 대회별로 미등록 100/200점 규정이 있는 경우는 별도 규칙입니다.

## 단판 내기에서 꼴찌 한 명을 정하는 별도 규칙

공식 점수 자체는 변경하지 않고 아래 순서로만 비교합니다.

1. 공식 점수가 가장 낮은 사람.
2. 동점이면 남은 타일 수가 더 많은 사람.
3. 수도 같으면 남은 타일의 벌점값을 큰 순서대로 한 장씩 비교. 조커 값은 30.
4. 모두 같으면 해당 동점자만 서로 다른 1~13 숫자를 서버에서 추첨. 높은 숫자가 꼴찌. 추첨 결과는 경기 결과에 고정 저장.

2~4번은 제조사 공식 순위 규정이 아닌 야볼의 단판 내기 규칙입니다. 별도의 미등록 벌점은 없습니다. 누적 여러 판 대회가 아닌 한 판마다 결과를 정합니다.

## 온라인 동작

- 2~4인 방, 전원 준비 후 5초 뒤 동시 시작. 설정 변경은 준비를 취소시킵니다.
- 내기 기본값은 없음, 스타벅스·메가커피·컴포즈커피 아이스 아메리카노 선택.
- 내 패만 전달하고 상대 패·풀·난수 상태는 서버에 둡니다. 차례·소유 타일·첫 등록·조합 판정은 서버가 검사합니다.
- 공용판 편집은 공유하되, 불완전한 배치는 턴 종료로 확정할 수 없습니다.
- 백그라운드에서도 시간이 흐르고, 서버의 마감 시각으로 만료를 처리합니다. 진행 중 게임 화면 닫기는 방 나가기나 일시정지가 아닙니다.
- 경기 중 방 나가기로 내기를 피할 수 없습니다. 화면만 닫았다가 다시 열 수 있습니다.
- 서버가 만료 시 이미 완성된 배치를 자동 확정하는 것은 온라인 버튼 입력을 보완하는 처리입니다.
- 풀이 빈 경기에서 최소 합계 동점은 공동 승자로 표시하고 점수 합계가 0이 되도록 나눕니다. 단판 꼴찌는 위 동점 규칙으로 한 명을 정합니다.

로컬 온라인 연결 테스트는 승인 회원 대신 테스트 참가자 1~4를 사용하는 별도 서버입니다. 운영 서비스 인증을 우회하는 기능은 배포 파일에 포함하지 않습니다.

## 결과와 회원 월간 랭킹

- 종료 결과의 순위는 공식 점수순입니다. 같은 점수는 공동 순위이며 내기 꼴찌 표시는 별도입니다.
- 결과에는 우측 상단 닫기만 있습니다. 누르면 방장과 참가자 모두 방에서 나와 로비로 돌아갑니다. 다시하기 버튼·방장 검토 대기 문구는 표시하지 않습니다.
- 회원 전체 월간 랭킹 TOP 30은 **1위 횟수 → 승률 → 누적 공식 점수**로 정합니다. 모두 같으면 공동 순위입니다.
- 1위는 공식 승자만 집계합니다. 공식 공동 승리도 각 회원에게 승리 1회이며, 승률은 승리 수 / 참가 수입니다. 가운데 순위와 꼴찌를 같은 ‘패’로 묶지 않고 꼴찌 수를 따로 표시합니다.
- 경기 종료 때 전원을 한 번만 집계합니다. 새로고침·결과 재열기·닫기는 집계 횟수를 늘리지 않습니다.
- 한국 시간 매월 1일 0시에 새 달 집계로 바뀝니다. 현재 달만 보관하고 과거 월별 기록은 누적 보관하지 않습니다. 이전 달에 끝난 경기를 늦게 읽어도 새 달에 더하지 않습니다.


## 배포와 운영

1. `supabase/migrations/051_rummikub.sql` 적용. 전체 방 상태와 월간 집계 테이블은 private 스키마이며 service_role만 RPC를 호출합니다.
2. `node build-rummikub-edge.mjs`로 서버 번들을 갱신하고 `rummikub-room` 함수를 배포합니다. 기존 서버 환경변수를 사용합니다.
3. `dist` 변경을 main으로 반영하면 GitHub Pages가 배포합니다.

결과 창은 우상단 닫기만 표시하며 누르면 실제 방을 떠나 로비로 돌아갑니다. 경기 중 닫기는 화면만 접고 서버 시간은 계속 진행합니다.

월간 TOP30은 1위 횟수, 승률, 공식 누적 점수 순입니다. 완전 동점은 공동 순위입니다. 한국시간 매월 1일 00시부터 새 달만 표시하고 이전 달 집계는 정리합니다. 월간 기록은 경기 종료 상태를 저장하는 동일 트랜잭션에서 round별 한 번만 반영합니다. 테스트 계정·샘플 경기·미리보기 페이지는 배포에 포함하지 않습니다.
